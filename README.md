# PhoneTemp APK patches

`original/` holds the app as uploaded (no source). `./build.sh` patches its bytecode and writes
`dist/PhoneTemp-1.0.1-debug.apk`:

- **System font** – `TypeKt` now uses `FontFamily.Default` for both the display and mono families, so
  every screen follows the phone's system font instead of the bundled Manrope / DM Mono.
- **Colour-ramped thermal ring** – `patch/GradientRing.smali` (generated by `patch/gen.py`) replaces the
  ring's Canvas drawing: the fill is a sweep gradient built from the theme's state colours
  (cool → normal → warm → hot → critical, aligned with the 20–50 °C scale), with a soft halo, so the
  bar changes colour as it grows.

The rebuilt APK is signed with a different debug key, so uninstall the old build before installing.
